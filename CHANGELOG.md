# Changelog

All notable changes to the Schema Markup Auditor extension will be documented in this file.

## [1.0.0] - 2025-01-03

### Added
- Initial release of Schema Markup Auditor
- JSON-LD schema extraction and display
- Microdata schema extraction and display
- RDFa schema extraction and display
- Schema validation with error and warning detection
- AI-powered recommendations via OpenAI, Anthropic, and Google
- Comprehensive audit reporting
- Export functionality for audit reports
- Settings management for AI configuration
- Visual dashboard with schema statistics
- Code viewer with copy functionality
- Support for 15+ common schema types validation
- Auto-analyze option for automatic AI recommendations
- User-friendly interface with tabbed navigation
- Local storage for API keys and settings

### Schema Types Supported
- Organization
- Person
- Article / NewsArticle / BlogPosting
- Product
- Review
- Event
- LocalBusiness
- Recipe
- VideoObject
- FAQPage
- HowTo
- BreadcrumbList
- WebSite

### Validation Features
- Missing @context detection
- Missing @type detection
- Required property validation
- Type-specific property checks
- JSON syntax validation
- Microdata structure validation

### AI Features
- Context-aware schema recommendations
- Missing schema type suggestions
- Property improvement recommendations
- Best practices guidance
- Priority-based suggestions
